[앱 1.15 적용 정책]
앱의 내 테마는 배경마다 하나씩 표시합니다. 같은 배경의 배치/스킨 저장본은 별도 항목으로 늘지 않습니다.
PC 작업 파일의 배치는 미리보기용으로 남지만, 앱에 테마를 적용할 때는 현재 위젯 구성과 위치/크기를 유지합니다.
앱에서 내보내는 ZIP에는 배치가 포함되지 않습니다. 아래 이전 설명보다 이 정책을 우선합니다.

라이브테마 스튜디오 — PC 제작자 편집기 첫 버전

열기: http://127.0.0.1:8787/creator/
서버가 꺼져 있으면 이 폴더의 '제작기_실행.cmd'를 실행하세요.
이 PC와 에뮬레이터에서만 쓰는 테스트입니다. 인터넷 공개 서비스가 아닙니다.

1. 웹 왼쪽에는 커뮤니티에 공유된 사용자 테마만 표시됩니다.
   앱의 기본 테마는 차량 앱의 테마 → 기본 테마에서 선택합니다.
   웹에서는 사용자 테마를 선택하거나 새 테마 만들기/테마 열기로 제작을 시작합니다.
   각 사용자 테마의 ZIP 다운로드로 원본 패키지를 받을 수 있습니다.
2. 미리보기에서 위젯을 선택하면 오른쪽에 그 위젯의 디자인이 나옵니다.
3. 테마 커스텀 / 기본 심플 / 기본 포커스 / 기본 클래식 중에서 선택합니다.
   모든 디자인은 위젯 바탕과 모서리 장식이 없습니다. 커스텀에서는 글자·강조·보조 색, 글꼴을 편집합니다.
   기본 디자인을 선택해도 원래 커스텀 스킨은 유지하며, 커스텀으로 돌아오면 복원됩니다.
4. 위젯을 끌어 위치를 바꾸고 모서리로 가로·세로 크기를 조절합니다.
   '정사각형으로'도 가능합니다. 16px 간격과 중앙선에 맞춰 배치할 수 있습니다.
5. 3분할·2분할·전체화면을 각각 선택해서 배치합니다. 서로 독립적으로 저장됩니다.
   차량 앱의 3분할 기본 보기에서는 시계를 고정하고 다른 위젯을 세로로 모아 표시합니다.
   PC 배치 미리보기는 자유 배치 편집 기준이며 차량 기본 보기와 완전히 같지는 않습니다.
6. 'JSON 저장'은 다음에 다시 편집할 설정 파일입니다.
   '테마 열기'는 JSON을 불러옵니다. 아직 ZIP을 편집기로 다시 여는 기능은 없습니다.
7. '테마 ZIP 내보내기'로 배경 참조와 위젯 스킨, 세 화면 배치를 함께 저장합니다.
   차량 앱으로 파일을 공유해서 가져오거나 아래 커뮤니티 방식을 사용하세요.
8. '테스트 커뮤니티에 공유' 후 차량 앱 → 테마 → 커뮤니티 → 다운로드.
   다운로드한 테마는 내 테마에 저장되며 미리보기에서 적용할 수 있습니다.

배경 원본
 - 창작마당 작품 번호 연결은 각자 PC에 내려받은 원본을 이 PC 안에서만 미리 보는 선택 기능입니다(저장소·APK에는 원본 없음).
- Windy 2347484937 / Winter 1929493662 / Lazy River 3519888361.
- APK와 공유 ZIP에는 창작마당 원본을 넣지 않습니다. 작품 번호만 들어갑니다.
- 받는 기기에도 해당 원본 연결이 필요합니다. 작품 번호만으로 Steam에서 자동 다운로드하지 않습니다.
- 모든 Wallpaper Engine 장면·셰이더·스크립트를 호환하는 것은 아닙니다.
- 내 MP4는 64 MiB 이하, 시계 글꼴 TTF/OTF는 4 MiB 이하입니다.
  직접 소유하거나 공유 허락을 받은 파일만 묶으세요.

현재 제작 범위
- 시계, 캘린더, 음악, 메모, D-day, 날씨·강수, 차량 배터리의 표시·스킨·배치.
- 새로운 모양은 색·글꼴·크기 조합으로 제작합니다.
- 새로운 위젯 데이터 기능, 임의 HTML/JavaScript, SceneScript 플러그인 실행은 아직 지원하지 않습니다.
- PC의 곡·날씨·배터리 값은 디자인용 예시입니다. 차량 앱은 실제 연결 값 또는 확인 불가를 표시합니다.
- 브라우저와 Android의 글꼴·렌더링 차이가 있어 마지막 확인은 차량 에뮬레이터에서 합니다.
- 변경 사항은 JSON/ZIP으로 저장해야 합니다. 페이지를 닫으면 저장하지 않은 편집은 사라집니다.
- 공유 파일에는 메모 내용·개인 일정·현재 곡·차량 값이 포함되지 않습니다.

구조와 다음 제작기 단계
- Wallpaper Engine은 장면 편집기+SceneScript 또는 HTML/CSS/JS로 동작을 제작하고,
  제작자가 노출한 색상·슬라이더 같은 속성을 일반 사용자가 조절하는 방식입니다.
- 우리도 '소비자는 테마 선택/위젯 배치', '제작자는 PC에서 테마 패키지 제작'으로 나눴습니다.
- 다음 확장은 읽기 전용 데이터 바인딩(시간/곡 정보/배터리)과 제한된 위젯 레이아웃 규격입니다.
  차량 제어 권한이나 임의 실행 코드를 공유 ZIP에 열어주는 방식은 현재 구현 범위에 없습니다.

- 충전 실제 상태: Android Automotive EV_CHARGE_STATE 읽기.

- 충전 상태 읽기 권한을 거절하거나 미지원 차량이면 확인 불가로 표시합니다.
- 충전 시작/중지 등 차량 제어 기능은 없습니다. 실차와 스토어 심사는 미검증입니다.

로컬 커뮤니티
- Python 표준 라이브러리, 127.0.0.1:8787에만 바인딩합니다.
- 에뮬레이터는 10.0.2.2:8787로 이 PC에 연결합니다.
- 디버그 APK에서만 로컬 HTTP를 허용합니다. 외부 서비스는 HTTPS가 필요합니다.
- ZIP allowlist, 크기 제한, SHA256 확인, 새 UUID 폴더 가져오기를 사용합니다.
- 인증·계정·신고·저작권 운영·공개 서버는 아직 없습니다. 외부 공개하지 마세요.
